
# 💸 SpendWise - Personal Expense Tracker

## Project Description
SpendWise is a Python-based expense tracking application
that helps users manage their daily expenses.

## Features
- Add expenses
- Categorize expenses
- View total spending
- Calculate average expenses
- Interactive pie charts
- Monthly spending analysis
- Delete transactions
- Download expense records as CSV
- SQLite database storage

## Technologies
- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## Installation

Install the required libraries:

pip install -r requirements.txt

Run the application:

streamlit run app.py
